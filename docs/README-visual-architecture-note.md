# Görsel Mimari Notu

KeskinLab ders içeriklerinin görsel üretiminde bağlayıcı kurallar için `docs/content-visual-architecture.md` dosyası esas alınır.

Bu belge özellikle şu kararları kalıcılaştırır:

- kimya/laboratuvar metaforları marka unsuru olarak kullanılmaz,
- yalnız repository'deki gerçek KeskinLab logo/brand asset'leri kullanılır,
- her öğretim teması için ayrı görsel sistem tanımlanır,
- style frame onayı olmadan toplu üretime geçilmez,
- jenerik Canva/AI eğitim şablonları ve clipart-kart estetiği reddedilir,
- her ekran pedagojik bir işlev taşır.
